# Simulateur politique 2027

Objectif :
Simuler les conséquences institutionnelles possibles
de l’élection présidentielle de 2027.

Le projet ne cherche pas à prédire les résultats,
mais à explorer les configurations politiques plausibles :

- coalition avec le président
- cohabitation
- présidence isolée
- fragmentation parlementaire

Le modèle repose sur :

1. Présidentiables plausibles
2. Influence politique
3. Acceptables / refusés
4. Duels présidentiels
5. Alliances gouvernementales
6. Alliances réciproques
7. Porosité tactique
8. Pivot gouvernemental

Concepts clés :

- alliances réciproques
- densité mutuelle
- porosité tactique
- hostilité agrégée
- pivot systémique
- gouvernement minoritaire survivant

Le simulateur doit rester :
- neutre politiquement
- descriptif
- institutionnel
- pédagogique

Il ne doit pas recommander
une orientation politique,
mais montrer les conséquences plausibles
des configurations produites.

Les règles détaillées du modèle sont décrites dans
CALCULATION_RULES.md.
